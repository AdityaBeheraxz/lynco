# Lynco  
AI-Powered Career Recommendation & Internship Matching Platform for BPUT Students

## 🚀 Project Description  
Lynco is a web application designed to help students of **Biju Patnaik University of Technology (BPUT)** find career-path recommendations and relevant internship opportunities by leveraging AI.  
It simplifies the process of matching students’ skills and interests with suitable career and internship opportunities — making career decisions more data-driven and personalized.

---

## 🧩 Key Features  
- 🎯 Personalized career path suggestions based on user profile, skills, and interests  
- 💼 AI-based internship matching for BPUT students  
- 📱 Responsive and modern UI  
- 🔒 Secure backend for storing student data and recommendations  
- 🧠 Built with modular, scalable architecture for future institutions too
